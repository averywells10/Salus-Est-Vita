# Salus est Vita

*Health is life.*

Salus est Vita is a free website for tracking workouts and food in one place. Users can log exercises, track meals and macros, and see their progress, on a phone or a computer.

**Live site:** [paste your GitHub Pages link here]

## Features

- **Workouts:** log exercises, sets, reps, and weight
- **Food:** log meals, calories, protein, carbs, and fat
- **Log in:** private accounts so each user sees only their own data
- **Works on any screen:** phone, tablet, and laptop

### Coming soon

- Dashboard with progress charts
- Personalized workout and meal recommendations

## Built with

- HTML, CSS, and JavaScript
- Visual Studio Code
- GitHub and GitHub Pages (hosting)
- Supabase (SQL database and logins)

## Project structure

| File | What it does |
| --- | --- |
| `index.html` | Home page |
| `workouts.html` | Workout tracker |
| `food.html` | Food and macro tracker |
| `login.html` | Log in and sign up |
| `style.css` | Styles for every page, including the phone layout |
| `script.js` | Phone menu and page behavior |

## How to run it

1. Clone the repository in VS Code (**Ctrl+Shift+P > Git: Clone**).
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.
